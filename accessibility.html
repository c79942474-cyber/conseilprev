Modes d'affichage

Personnalisez votre expérience

📖
Mode lecture
Optimisé pour une lecture prolongée et confortable.
  • Largeur de texte optimisée
  • Interlignage augmenté
  • Contraste doux pour la fatigue oculaire
  • Idéal pour les documents longs
T
Mode dyslexie
Adapte la typographie pour faciliter la lecture.
  • Police spécialement conçue
  • Espacement des lettres augmenté
  • Espacement des mots optimisé
  • Meilleure détection des caractères
👁
Contraste élevé
Renforce les contrastes pour une meilleure visibilité.
  • Contraste texte/fond amplifié
  • Bordures plus marquées
  • Couleurs plus distinctes
  • Idéal pour la déficience visuelle
⚙️
Thème clair / sombre
Adaptez l'interface à vos préférences et conditions d'éclairage
🌙
Mode sombre
Interface sombre, parfaite pour les environnements peu éclairés. Réduit l'éblouissement et économise l'énergie sur écrans OLED.
☀️
Mode clair
Interface lumineuse, idéale pour les environnements bien éclairés. Réduit la fatigue oculaire en journée.
🔊
Retour sonore
Sons subtils pour confirmer les actions d'accessibilité

Lorsque vous activez ou désactivez un mode d'accessibilité, un son subtil vous confirme l'action :

Tonalité montante
: mode activé
Tonalité descendante
: mode désactivé

Vous pouvez désactiver les sons dans le panneau d'accessibilité Alt+A.

Conformité

Niveaux WCAG 2.1 & RGAA

Le WCAG (Web Content Accessibility Guidelines) est l'ensemble de normes techniques qui améliore l'accessibilité du contenu web pour les personnes en situation de handicap. Le RGAA (Référentiel Général d'Amélioration de l'Accessibilité) est le cadre national français, aligné sur WCAG 2.1 niveaux A et AA.

A
Niveau A
Exigences minimales d'accessibilité. Indispensable pour éviter les obstacles majeurs à la navigation.
✓ Conforme
AA
Niveau AA
Norme cible de notre plateforme. Recommandée par l'UE, le RGAA et la plupart des obligations légales.
✓ Objectif
AAA
Niveau AAA
Niveau d'excellence. Certaines fonctionnalités de notre plateforme y répondent déjà.
